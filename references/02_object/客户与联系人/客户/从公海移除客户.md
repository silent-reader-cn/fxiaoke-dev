# 从公海移除客户

## 描述

从公海移除客户

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/data/remove?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| owner | String | 否 | 移除公海后的客户数据的负责人，可以通过文档中协同接口菜单下v1接口获取。isKeepOwner=true时可以不用传该参数 |
| isKeepOwner | Boolean | 是 | 移除公海是否保持原负责人，true表示保持原负责人 |
| apiName | String | 是 | apiName,可以是AccountObj、LeadsObj |
| objectIDs | List | 是 | 要移除的客户数据id，可以通过客户列表接口过滤出某个公海内的客户 |
| objectPoolId | String | 是 | 公海的数据id，可以通过公海对象条件查询接口获取 |

## 请求示例

```json
{
  "data": {
    "owner": "1000",
    "objectPoolId": "95a39b6bf2a64d288c692594e8d2627f",
    "apiName": "AccountObj",
    "isKeepOwner": false,
    "objectIDs": [
      "5cf7742adcd3ec000196557d"
    ]
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
