# 删除公海对象接口

## 描述

删除公海对象接口

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/data/pool_service/service/delete?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| api_name | String | 是 | 固定值HighSeasObj |
| id | String | 是 | 删除的公海数据id，可以通查询公海列表接口获取 |
| target_pool_id | String | 否 | 不传在删除时删除公海下所有客户，如果需要将删除的公海下客户转移到另外一个公海，请传另外一个公海的数据id |

## 请求示例

```json
{
  "data": {
    "target_pool_id": "60e7b385de9f0b0001246de9",
    "api_name": "HighSeasObj",
    "id": "5fa927a7db4341f6a20490e1bac4dd8c"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
