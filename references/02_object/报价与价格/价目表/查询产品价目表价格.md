# 查询产品价目表价格

## 描述

查询产品价目表价格

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/availableRange/getRealPrice?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| accountId | String | 否 | 客户ID |
| partnerId | String | 否 | 合作伙伴ID |
| fullProductList | List | 是 | 产品列表 |
| productId | String | 否 | 产品ID |
| mcCurrency | String | 否 | 币种 |
| object_data | Map | 否 | 数据 |
| account_id | String | 否 | 客户ID |
| details | Map | 否 | 数据 |
| SaleContractLineObj | List | 否 |  |
