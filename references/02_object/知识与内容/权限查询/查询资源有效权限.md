# 查询资源有效权限

## 描述

查询当前用户对指定知识资源（知识空间、知识文件夹）的最终有效权限级别。对文件夹返回的是从空间及上级文件夹逐级继承后的最终权限。

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/knowledge/folder/effectivePermission?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据 |
| resourceType | String | 是 | 资源类型：`SPACE` 知识空间、`CATEGORY` 知识文件夹。只查文件夹时必须传 `CATEGORY`；`SERVICE_KNOWLEDGE` 及其他非上述取值不支持查询知识条目权限 |
| resourceId | String | 是 | 资源 ID，不可缺省或传空。`SPACE` 时为空间 ID；`CATEGORY` 时为文件夹 folderCode |

## 请求示例

```json
{
  "data": {
    "resourceType": "CATEGORY",
    "resourceId": "16"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| data | object | 返回数据 |
| resourceId | String | 资源 ID |
| permission | String | 当前用户对该资源的最终权限级别：`MANAGE` 管理、`EDIT` 编辑、`DOWNLOAD` 下载、`VIEW` 查看、`NONE` 无权限 |

## 返回示例

```json
{
  "traceId": "E-O.fktest4234.1000-20260914112000-xxxxxx",
  "errorDescription": "success",
  "errorMessage": "success",
  "errorCode": 0,
  "data": {
    "resourceId": "16",
    "permission": "VIEW"
  }
}
```

## 注意事项

- 权限级别由高到低为 MANAGE > EDIT > DOWNLOAD > VIEW > NONE ，高级别默认包含低级别能力（如 DOWNLOAD 包含查看）。
- 返回 NONE 表示当前用户对该资源无权限； NONE 不应按可查看处理。
- 对外路径含 folder ，但 resourceType 仍支持 SPACE （此时 resourceId 传空间 ID）。只查文件夹时必须传 resourceType=CATEGORY 且 resourceId=folderCode 。
- resourceType 、 resourceId 缺省或为空时返回参数错误，不会返回 NONE 。
- 本接口仅支持知识空间与知识文件夹，暂不支持查询知识条目的有效权限。传入 SERVICE_KNOWLEDGE 或其他非 SPACE / CATEGORY 取值时： resourceId 有值则返回 permission=NONE （不代表真实权限，请勿据此判断）； resourceId 为空则返回参数错误。
- 需要使用同一权限级别枚举的接口还有 批量查询文件夹权限 。
- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
