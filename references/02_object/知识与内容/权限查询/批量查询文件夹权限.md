# 批量查询文件夹权限

## 描述

批量查询当前用户在多个知识空间内、对其可见的各知识文件夹的有效权限级别。

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/knowledge/folder/permissions?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据 |
| spaceIds | List[String] | 是 | 知识空间 ID 列表，支持一次传入多个空间。字段必须出现在请求体中：不传或为 null 返回参数错误；传空数组 `[]` 时返回空列表 |

## 请求示例

```json
{
  "data": {
    "spaceIds": ["space-001", "space-002"]
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| data | object | 返回数据 |
| folderPermissions | Array | 文件夹权限平铺列表 |
| folderPermissions[].folderCode | String | 知识文件夹 code |
| folderPermissions[].permission | String | 当前用户对该文件夹的最终权限级别，取值见[查询资源有效权限](https://developer.fxiaoke.com/openapi_v2/object/KnowledgeAndContent/permission/effectivePermission.html) |

## 返回示例

```json
{
  "traceId": "E-O.fktest4234.1000-20260914113000-xxxxxx",
  "errorDescription": "success",
  "errorMessage": "success",
  "errorCode": 0,
  "data": {
    "folderPermissions": [
      {
        "folderCode": "16",
        "permission": "EDIT"
      },
      {
        "folderCode": "17",
        "permission": "VIEW"
      }
    ]
  }
}
```

## 注意事项

- 仅返回当前用户可访问（ VIEW 及以上权限）的文件夹；不可访问的文件夹不会出现在结果中。
- spaceIds 不能省略：请求体不带该字段（或开平未补）会返回参数错误；传 [] 能过校验，结果为空列表。
- 请求体中的 minPermission 即使传入也不生效，本接口不会按该字段过滤结果。
- 同一文件夹 code 出现在多个空间时，权限合并后按最高级别返回一条；结果顺序不保证稳定，请勿依赖。
- 结果为跨空间的平铺列表，如需文件夹层级结构请使用 可见知识文件夹列表 。
- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
