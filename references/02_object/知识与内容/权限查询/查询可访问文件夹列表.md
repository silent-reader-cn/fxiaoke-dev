# 查询可访问文件夹列表

## 描述

查询当前用户在指定知识空间内可访问的知识文件夹 code 列表，常用于过滤知识条目列表、RAG 检索的可见范围。

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/knowledge/folder/accessibleCodes?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据 |
| spaceIds | List[String] | 是 | 知识空间 ID 列表，支持一次传入多个空间。字段必须出现在请求体中：不传或为 null 返回参数错误；传空数组 `[]` 时返回当前用户全企业范围内全部可访问（VIEW 及以上）的文件夹（含仅有文件夹级授权、无空间级权限的文件夹） |

## 请求示例

```json
{
  "data": {
    "spaceIds": ["space-001", "space-002"]
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| data | object | 返回数据 |
| folderCodes | List[String] | 当前用户可访问的知识文件夹 code 平铺列表 |

## 返回示例

```json
{
  "traceId": "E-O.fktest4234.1000-20260914114000-xxxxxx",
  "errorDescription": "success",
  "errorMessage": "success",
  "errorCode": 0,
  "data": {
    "folderCodes": ["16", "17", "18"]
  }
}
```

## 注意事项

- 返回结果为跨空间跨层级的平铺列表，仅包含当前用户可访问（ VIEW 及以上权限）的文件夹 code，不包含层级结构。
- spaceIds 不能省略：请求体不带该字段（或开平未补）会返回参数错误。不传与传 [] 行为不同：前者参数错误，后者为全企业范围查询。
- 请求体中的 minPermission 即使传入也不生效，本接口不会按该字段过滤结果。
- 返回的 folderCode 可直接用于 知识条目列表 中 category 字段的 IN 过滤条件，或作为 RAG 知识检索 的 folders 参数。
- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
