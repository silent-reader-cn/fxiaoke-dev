# 新建知识条目

## 描述

新建一条知识条目。知识库按「知识空间 → 知识文件夹 → 知识条目」三级组织，创建时必须通过 `category` 指定所属知识文件夹。

本接口为平台标准对象创建接口，通过 `dataObjectApiName` 指定对象，固定取值 `ServiceKnowledgeObj`。

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/data/create?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

详细字段说明请参考 [参数填写说明](https://developer.fxiaoke.com/openapi_v2/start/guide/param.html)

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| triggerApprovalFlow | Boolean | 否 | 是否触发审批流，不传时默认为 true，表示触发 |
| triggerWorkFlow | Boolean | 否 | 是否触发工作流，不传时默认为 true，表示触发 |
| hasSpecifyTime | Boolean | 否 | 是否可传创建时间，不传时默认为 false，表示忽略 object_data 中的 create_time 字段 |
| hasSpecifyCreatedBy | Boolean | 否 | 是否可传创建人，不传时默认为 false，表示忽略 object_data 中的 created_by 字段 |
| data | Map | 是 | 数据 |
| object_data | Map | 是 | 知识条目对象 |
| object_data.dataObjectApiName | String | 是 | 对象 apiName，固定值 `ServiceKnowledgeObj` |
| object_data.record_type | String | 是 | 固定值 `default__c` |
| object_data.title | String | 是 | 标题 |
| object_data.category | String | 是 | 所属知识文件夹 code，可通过[可见知识文件夹列表](https://developer.fxiaoke.com/openapi_v2/object/KnowledgeAndContent/spaceFolder/folderList.html)获取 |
| object_data.content_type | String | 是 | 内容类型：`text` 纯文本、`rich_text` 富文本、`enclosure` 附件 |
| object_data.text | String | 否 | 纯文本内容，`content_type=text` 时必填 |
| object_data.rich_text | String | 否 | 富文本内容（HTML），`content_type=rich_text` 时必填 |
| object_data.material_message | Array | 否 | 附件列表，`content_type=enclosure` 时必填。附件字段填写规范见[字段值说明](https://developer.fxiaoke.com/openapi_v2/start/guide/values.html) |
| object_data.permanent_validity | Boolean | 否 | 是否永久有效 |
| object_data.validity_begin_time | Long | 否 | 有效期开始时间，毫秒时间戳 |
| object_data.validity_end_time | Long | 否 | 有效期结束时间，毫秒时间戳 |
| object_data.summary | String | 否 | 简介 |
| object_data.author | String | 否 | 作者。不传时默认取当前操作员工姓名 |

## 请求示例

```json
{
  "data": {
    "object_data": {
      "dataObjectApiName": "ServiceKnowledgeObj",
      "record_type": "default__c",
      "title": "设备安装说明",
      "category": "16",
      "content_type": "rich_text",
      "rich_text": "<p>安装步骤</p>",
      "permanent_validity": true
    }
  }
}
```

## 注意事项

- content_type 决定正文字段： text 对应 text 、 rich_text 对应 rich_text 、 enclosure 对应 material_message ，不匹配时保存的正文可能为空。
- public_status （发布状态）、 read_count （阅读数）、 be_helpful 、 not_helpful 等字段由系统维护，无需也不允许传入；发布状态只能通过 发布 、 下架 接口变更。
- 新建成功的知识条目默认为「未发布」状态，需要对外可见时请调用 发布知识条目 。
- 人员、附件类字段遵循标准对象接口的 openUserId / mediaId 约定，网关自动完成双向转换。
- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
