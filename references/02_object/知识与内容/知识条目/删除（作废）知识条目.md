# 删除（作废）知识条目

## 描述

作废（删除）指定知识条目。本接口为平台标准对象作废接口，对象由 `dataObjectApiName` 指定，固定取值 `ServiceKnowledgeObj`。

作废不是物理删除：数据进入回收站，CRM 站内与本列表接口均不再返回；本期未开放恢复接口，请谨慎操作。

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/data/invalid?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据 |
| dataObjectApiName | String | 是 | 对象 apiName，固定值 `ServiceKnowledgeObj` |
| object_data_id | String | 是 | 知识条目 ID |

## 请求示例

```json
{
  "data": {
    "dataObjectApiName": "ServiceKnowledgeObj",
    "object_data_id": "68c1a0f0abcd0001"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.fktest4234.1000-20260914102000-xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 每次调用作废一条数据，批量作废请循环调用本接口。
- 已发布（ public_status=1 ）的条目建议先 下架 再作废。
- 作废后条目在 CRM 站内不再可见，列表查询默认不再返回该数据。
- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
