# 知识空间详情

## 描述

查询指定知识空间的详细信息。

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/knowledge/space/detail?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据 |
| spaceId | String | 是 | 知识空间 ID |

## 请求示例

```json
{
  "data": {
    "spaceId": "space-001"
  }
}
```

## 返回参数

返回结构与[可见知识空间列表](https://developer.fxiaoke.com/openapi_v2/object/KnowledgeAndContent/spaceFolder/spaceList.html)中的单条空间数据（`spaces[]` 元素）一致；其中 `permission` 字段本接口不回填、恒为 `null`，如需查询空间权限请调用[查询资源有效权限](https://developer.fxiaoke.com/openapi_v2/object/KnowledgeAndContent/permission/effectivePermission.html)。

## 注意事项

- 空间不存在或当前用户无查看权限时返回失败，不返回空间数据。
- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
