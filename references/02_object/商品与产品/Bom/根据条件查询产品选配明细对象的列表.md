# 根据条件查询产品选配明细对象的列表

## 描述

根据条件查询产品选配明细对象的列表

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/data/query?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| returnTotalNum | Int | 否 | 列表总数类型,1:返回精确总数,2:返回预估总数,3或不传:不返回总数(响应更快) |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| data | Map | 是 | 数据map |
| dataObjectApiName | String | 是 | 对象的api_name，固定取值：BOMObj |
| search_query_info | Map | 是 | [查询条件说明](https://developer.fxiaoke.com/openapi_v2/FAQ/query-condition.html) |
| limit | Int | 是 | 分页条数(最大值为100) |
| offset | Int | 是 | 偏移量(从0开始、数值必须为limit的整数倍) |
| filters | List | 是 | 过滤条件列表 |
| field_name | String | 是 | 字段名 |
| field_values | List[String] | 是 | 字段值 |
| operator | String | 是 | 操作符，详细见下方[operator参数说明] |
| orders | List | 是 | 查询条件 |
| fieldName | String | 是 | 字段名 |
| isAsc | Boolean | 是 | 是否升序(如果是true，按照升序排列，如果是false，则按照倒序排列) |
| fieldProjection | List[String] | 是 | 返回字段列表,取值对象字段中的apiName |

### operator 参数说明

可以直接使用对象列表页面中的查询条件，查看[如何获取列表中的查询条件](https://developer.fxiaoke.com/openapi_v2/FAQ/query-condition.html)

| 参数 | 参数含义 | 说明 | 参数 | 参数含义 | 说明 |
| --- | --- | --- | --- | --- | --- |
| EQ | 等于 |  | N | 不等于 | 可以查出空值 |
| GT | 大于 |  | GTE | 大于等于 |  |
| LT | 小于 |  | LTE | 小于等于 |  |
| LIKE | 包含 |  | NLIKE | 不包含 |  |
| IS | 为空 |  | ISN | 不为空 |  |
| IN | 属于 |  | NIN | 不属于 |  |
| BETWEEN | 介于 |  | NBETWEEN | 不介于 |  |
| STARTWITH | 开始于 |  | ENDWITH | 结束于 |  |
| HASANYOF | 有重叠元素 |  | NHASANYOF | 没有重叠 |  |

## 请求示例

```json
{
  "includeNull": true,
  "data": {
    "search_query_info": {
      "offset": 0,
      "limit": 1,
      "orders": [
        {
          "fieldName": "create_time",
          "isAsc": true
        }
      ],
      "fieldProjection": [
        "name"
      ],
      "filters": [
        {
          "operator": "EQ",
          "field_name": "name",
          "field_values": [
            "603dabc14ae65400011aec90"
          ]
        }
      ]
    },
    "dataObjectApiName": "BOMObj"
  }
}
```
