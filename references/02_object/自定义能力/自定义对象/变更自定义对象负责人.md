# 变更自定义对象负责人

## 描述

变更自定义对象负责人

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/custom/v2/data/changeOwner?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**本接口只适用于自定义对象（即对象的ApiName以__c结尾的对象）**

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| idList | List | 是 | 数据id列表 |
| dataObjectApiName | String | 是 | 对象的apiName |

## 请求示例

```json
{
  "data": {
    "idList": "",
    "dataObjectApiName": ""
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化;

## 特殊说明

**与V1自定义对象创建接口区别说明**： V1接口入参:

```json
{
	"corpAccessToken": "CORP_ACCESS_TOKEN",
	"corpId": "CORP_ID",
	"currentOpenUserId": "1000",
	"data": {
		"dataObjectApiName": "object_Nyeoj__c",
		"dataList": [{
				"objectDataId": "5d27fe3642639b00017160e8",
				"ownerId": [
					"1000"
				]
			},
			{
				"objectDataId": "5d27f9466e048f00013ae503",
				"ownerId": [
					"1000"
				]
			}
		]
	}
}
```
V2接口入参:

```json
{
	"data": {
		"dataObjectApiName": "object_Nyeoj__c",
		"Data": [{
			"objectDataId": "5a9914fcf125ae0a1axxxxxx",
			"ownerId": [
				"1000"
			]
		}]
	}
}
```
注意关键字从`dataList`变为了`Data`。
