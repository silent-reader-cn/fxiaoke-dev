# 退回线索到线索池

## 描述

退回线索

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/data/return?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| apiName | String | 是 | 对象的api_name,只支持客户和销售线索(AccountObj和LeadsObj) |
| objectIds | List[String] | 是 | 被退回的数据Id列表 |
| objectPoolId | String | 是 | 线索池Id或者客户公海Id |
| backReason | String | 是 | 退回原因：0,1,2,other |
| backReason__o | String | 否 | backReason传 other 需要加上文字说明，不然原因内容是空 |

## 请求示例

```json
{
  "data": {
    "objectPoolId": "4cc3773d4be54167a73ce0da76385047",
    "apiName": "AccountObj",
    "backReason__o": "对接退回",
    "objectIds": [
      "5e9949cebb9f720001a5615f"
    ],
    "backReason": "0"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
