# 发送图文消息

## 描述

发送图文消息

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/message/send?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| toUser | List | 是 | 开放平台员工ID列表（消息接收者，目前最多支持500人） |
| msgType | String | 是 | 消息类型，取值为：articles |
| articles | List | 是 | 图文条目列表 ，一次最多允许7条图文消息 |
| articles.title | String | 是 | 标题，最长45个字符 |
| articles.author | String | 否 | 作者，最长8个字符 |
| articles.description | String | 否 | 摘要，最长140字符。 |
| articles.coverImage | String | 是 | 封面图片对应的mediaId |
| articles.coverImageInContent | Boolean | 否 | 当articles.type为"TEXT"时，内容中是否显示图片(false不包含，true包含，默认false) |
| articles.type | String | 是 | 图文消息内容类型（"TEXT","URL"） |
| articles.content | String | 是 | 图文消息内容，当imageTextType为"URL"时表示链接地址。 |

## 请求示例

```json
{
   "toUser":[
      "TOUSER1",
      "TOUSER2"
   ],
   "msgType":"articles",
   "articles":[
      {
         "title":"这是标题",
         "author":"作者",
         "description":"这是普通文章样例",
         "coverImage":"mediaId",
         "coverImageInContent":true,
         "type":"TEXT",
         "content":"这是文章内容"
      },
      {
         "title":"这是标题",
         "author":"作者",
         "description":"这是跳转样例",
         "coverImage":"mediaId",
         "type":"URL",
         "content":"www.aaa.com"
      }
   ]
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
