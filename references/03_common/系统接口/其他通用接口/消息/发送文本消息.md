# 发送文本消息

## 描述

发送文本消息

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/message/send?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| toUser | List | 是 | 开放平台员工ID列表（消息接收者，目前最多支持500人） |
| msgType | String | 是 | 消息类型，取值为：text |
| text | Map | 否 | 二级对象，文本内容详情 |
| &ensp: content | String | 是 | 文本消息内容 |

## 请求示例

```json
{
   "toUser":[
      "TOUSER1",
      "TOUSER2"
   ],
   "msgType":"text",
   "text":{
      "content":"这是一条文本消息"
   }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
