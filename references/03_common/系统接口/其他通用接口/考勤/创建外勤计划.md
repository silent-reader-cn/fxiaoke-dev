# 创建外勤计划

## 描述

创建外勤计划

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/seniorOutsideAttendance/createPlan?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据集 |
| planTime | Long | 否 | 计划执行时间，未来某个时间的时间戳 |
| checkTypeId | String | 否 | 外勤类型Id |
| executorId | String | 否 | 计划执行人的openUserId |
| assistantIds | List | 否 | 协访人的openUserId列表 |
| extFields | Map | 否 | 外勤计划的配置自定义字段模块，字段描述参考高级外勤 |
| mainObject | Map | 否 | 主对象数据 |
| apiName | String | 否 | 关联的主对象的apiName |
| dataId | String | 否 | 关联的主对象的Id |
| info | String | 否 | 客户的经纬度 |
| referenceObject | List | 否 | 从对象数据 |

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| checkinId | string | 外勤计划id |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0,
  "checkinId":"123456"
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
