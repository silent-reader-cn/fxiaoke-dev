# 获取高级外勤数据列表

## 描述

获取高级外勤数据列表

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/seniorOutsideAttendance/find?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| searchQuery | Map | 是 | 查询条件 |
| conditions | List | 否 | 过滤条件列表 |
| dataProjection | Map | 否 | 返回字段信息 |
| limit | Int | 否 | 获取数据条数,默认20,最大值为100 |
| offset | Int | 否 | 偏移量，从0开始、数值必须为limit的整数倍 |
| orders | List | 否 | 排序 |
| rangeConditions | List | 否 | 范围条件列表 |

## 请求示例

```json
{
  "includeNull": true,
  "searchQuery": {
    "rangeConditions": [
      {
        "fieldName": "last_modified_time",
        "from": 1482980437573,
        "to": 1482982437573
      }
    ],
    "offset": 1,
    "limit": 5,
    "orders": [
      {
        "ascending": true,
        "field": "name"
      }
    ],
    "conditions": [
      {
        "conditionType": "term_condition",
        "conditions": {
          "name": "209955435609544554121",
          "owner": "1000"
        }
      }
    ],
    "dataProjection": {
      "fieldNames": [
        "name",
        "owner"
      ]
    }
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| datas | List | 考勤记录列表 |
| totalNumber | Int | 总记录数 |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0,
  "datas":{},
  "totalNumber":"123456"
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
