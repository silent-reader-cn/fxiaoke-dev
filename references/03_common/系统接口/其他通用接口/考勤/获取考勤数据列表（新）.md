# 获取考勤数据列表（新）

## 描述

获取考勤数据列表（新）

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/attendance/find/v2?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| data | Map | 是 | 数据集 |
| ea | String | 是 | 企业账号 |
| userIds | List | 是 | 员工id列表 |
| pageSize | Int | 是 | 页容量 |
| pageNumber | Int | 是 | 页号 |
| pageType | Int | 是 | 固定值 |
| startTime | Long | 是 | 开始时间（毫秒时间戳） |
| endTime | Long | 是 | 结束时间（毫秒时间戳） |

## 请求示例

```json
{
  "includeNull": true,
  "data": {
    "pageNumber": 1,
    "pageType": 0,
    "userIds": [
      1000
    ],
    "pageSize": 20,
    "startTime": 0,
    "endTime": 0,
    "ea": "xxx"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
