# 获取外勤类型

## 描述

获取外勤类型

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/seniorOutsideAttendance/getCheckType?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| mainApiName | String | 否 | 关联主对象apiName |
| apiNames | List | 否 | 关联子对象apiName |

## 请求示例

```json
{
  "includeNull": true,
  "mainApiName": "AccountObj",
  "apiNames": [
    "ContactObj"
  ]
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| data | List | 考勤记录列表 |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0,
  "data":{}
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
