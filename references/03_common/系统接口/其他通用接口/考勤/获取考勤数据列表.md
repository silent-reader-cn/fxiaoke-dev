# 获取考勤数据列表

## 描述

获取考勤数据列表

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/attendance/find?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| startTime | Long | 是 | 开始时间戳(毫秒) |
| endTime | Long | 是 | 结束时间戳(毫秒)；endTime-startTime 不能大于40天 |
| pageSize | Int | 否 | 页容量（默认20 ，最大1000） |
| pageNumber | String | 否 | 页码（默认为1） |
| openUserIds | List | 是 | 被查询人员的openUserId列表；最多支持200人 |

## 请求示例

```json
{
  "includeNull": true,
  "pageNumber": 1,
  "pageSize": 20,
  "startTime": 1479229200000,
  "endTime": 1481043600000,
  "openUserIds": [
    "1000"
  ]
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | 错误码 |
| datas | List | 接口返回数据 |
| openUserId | String | 用户开平账号 |
| userName | String | 用户昵称 |
| createDateStr | String | 签到日期 |
| checkTime | Long | 打卡时间 |
| checkType | Int | 签到打卡类型: 0-签到、1-签退 |
| locationType | Int | 打卡方式: 0-经纬度、1-wifi |
| locationException | Int | 签到距离: 0-正常 、1-地点异常、2-wifi异常 |
| deviceId | String | 签到设备号 |
| checkAddress | Int | 打卡位置 |
| deviceException | Int | 设备异常: 0-正常、 1-异常 |
| checkId | Int | 数据唯一id |
| systemException | Int | 系统风险: 0- 正常、1- IOS越狱、2- Android 作弊软件、3- Android 伪造地址、4 模拟器、5 root |
| totalCount | Int | 总记录数 |

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
