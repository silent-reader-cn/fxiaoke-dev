# 查询数据修改记录接口

## 描述

查询数据修改记录接口

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/object/getNewLogInfoListForWeb?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| data | Map | 是 | 数据map |
| apiName | String | 是 | 对象apiName |
| objectId | String | 是 | objectId |
| pageNumber | Int | 是 | 页号 |
| pageSize | Int | 是 | 页容量 |
| operationTimeFrom | Long | 是 | 查询时间开始 |
| operationTimeTo | Long | 是 | 查询时间结束 |
| operationalType | String | 否 | 操作类型 |

## 请求示例

```json
{
  "includeNull": true,
  "data": {
    "apiName": "SPUObj",
    "pageNumber": 1,
    "operationalType": "system",
    "operationTimeTo": "1716998400000",
    "pageSize": 20,
    "objectId": "xxxxxxxxxxxxxxx",
    "operationTimeFrom": "1716825600000"
  }
}
```
