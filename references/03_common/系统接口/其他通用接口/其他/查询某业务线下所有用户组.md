# 查询某业务线下所有用户组

## 描述

查询某业务线下所有用户组

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/org/group?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| data | Map | 是 | 数据map |
| appId | String | 是 | 固定值：CRM |
| isFilterByUser | Boolean | 是 | 是否用context中的userId来过滤组中的createdBy |
| isPublic | Boolean | 是 | 是否公开组 |
| status | Int | 是 | 用户组状态:0启用1禁用 |
| page | Map | 是 | 分页参数 |
| pageSize | Int | 是 | 页容量 |
| currentPage | Int | 是 | 页号 |

## 请求示例

```json
{
  "includeNull": true,
  "data": {
    "isFilterByUser": true,
    "appId": "CRM",
    "isPublic": true,
    "page": {
      "pageSize": 20,
      "currentPage": 1
    },
    "status": 0
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
