# 根据条件查询对象数据，只做基本的数据查询

## 描述

根据条件查询对象数据，只做基本的数据查询

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/custom/v2/data/findSimple?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| data | Map | 是 | 数据map |
| dataObjectApiName | String | 是 | 对象的api_name |
| find_explicit_total_num | Boolean | 否 | 是否返回总数(true->返回total,false->不返回total总数。默认true。设置为false可以加快接口响应速度) |
| search_query_info | Map | 是 | [查询条件说明](https://developer.fxiaoke.com/openapi_v2/FAQ/query-condition.html) |
| limit | Int | 是 | 分页条数(最大值为100) |
| offset | Int | 是 | 偏移量(从0开始、数值必须为limit的整数倍) |
| filters | List | 是 | 过滤条件列表 |
| field_name | String | 是 | 字段名 |
| field_values | List[String] | 是 | 字段值 |
| operator | String | 是 | 操作符，详细见下方[operator参数说明] |
| orders | List | 是 | 查询条件 |
| fieldName | String | 是 | 字段名 |
| isAsc | Boolean | 是 | 是否升序(如果是true，按照升序排列，如果是false，则按照倒序排列) |
| field-projection | List[String] | 是 | 返回数据中包含的字段，为空则返回所有字段。如果指定的是计算字段、统计字段和引用字段，值不会实时计算 |

## 请求示例

```json
{
  "includeNull": true,
  "data": {
    "search_query_info": {
      "offset": "0",
      "limit": "10",
      "orders": [
        {
          "fieldName": "last_modified_time",
          "isAsc": "false"
        }
      ],
      "filters": {
        "operator": "GT",
        "field_name": "last_modified_time",
        "field_values": "[1744094120158]"
      }
    },
    "dataObjectApiName": "",
    "igonreMediaIdConvert": false,
    "field_projection": [
      "_id"
    ]
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
