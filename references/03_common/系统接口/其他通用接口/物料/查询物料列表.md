# 查询物料列表

## 描述

查询物料列表

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/material/queryMaterial?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| data | Map | 是 | 数据MAP |
| materialType | Int | 是 | 物料类型 : 1-查询产品(目前只支持产品) |
| productQueryArg | Map | 是 | 物料类型id集合 |
| status | Int | 是 | 状态 : 1-已启用 2-已停用 3-未启用（不传查询全部） |
| keyword | String | 是 | 搜索关键词 |
| groupId | String | 是 | 产品分组ID |
| pageNum | Int | 是 | 页号 |
| pageSize | Int | 是 | 页容量 |

## 请求示例

```json
{
  "includeNull": true,
  "data": {
    "materialType": 1,
    "productQueryArg": {
      "groupId": "分组ID",
      "keyword": "关键词",
      "status": 1
    },
    "pageSize": 20,
    "pageNum": 1
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
