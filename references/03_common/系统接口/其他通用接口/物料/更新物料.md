# 更新物料

## 描述

更新物料

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/material/updateMaterial?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据MAP |
| productId | String | 是 | 产品id |
| isUpdatePicture | Boolean | 是 | 是否更新图片 |
| materialType | Int | 是 | 物料类型：1-创建产品(目前只支持产品) |
| createProductArg | Map | 是 | 新增产品参数, materialType=1时必填 |
| name | String | 是 | 产品名称 |
| price | String | 是 | 价格 |
| discountPrice | String | 是 | 优惠价格 |
| videoUrl | String | 是 | 视频URL,只支持腾讯视频的URL, videoUrl和videoId只能传一个,详情图和视频必传一个 |
| videoId | String | 是 | 视频库的视频ID, videoUrl和videoId只能传一个,详情图和视频必传一个 |
| summary | String | 是 | 产品简介 |
| tryOutEnable | Boolean | 是 | 产品试用:true 关闭 false 打开 |
| tryOutButtonValue | Boolean | 是 | 按钮名称 |
| formId | Boolean | 是 | 表单id |
| headPictures | List | 是 | 产品封面图,最多传3张,建议尺寸为:750 * 360 |
| data | List | 是 | 图片数据，将图片转换为byte数组 |
| extension | String | 是 | 图片扩展名 |
| detailPictures | List | 是 | 产品详情图,最多传20张,详情图和视频必传一个 |
| data | List | 是 | 图片数据，将图片转换为byte数组 |
| extension | String | 是 | 图片扩展名 |

## 请求示例

```json
{
  "data": {
    "productId": "产品ID",
    "materialType": 1,
    "createProductArg": {
      "summary": "demoData",
      "formId": "demoData",
      "videoUrl": "demoData",
      "tryOutButtonValue": "demoData",
      "price": "demoData",
      "tryOutEnable": true,
      "name": "demoData",
      "discountPrice": "demoData",
      "detailPictures": {
        "extension": "jpg",
        "data": [
          1
        ]
      },
      "videoId": "demoData",
      "headPictures": {
        "extension": "jpg",
        "data": [
          1
        ]
      }
    },
    "isUpdatePicture": false
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
