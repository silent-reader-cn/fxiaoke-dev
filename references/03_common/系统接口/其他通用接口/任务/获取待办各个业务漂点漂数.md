# 获取待办各个业务漂点漂数

## 描述

获取待办各个业务漂点漂数

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/special/getUserTodoStats?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| appId | String | 否 | 要筛选的应用Id，不传查全部 |
| data | Map | 是 | data.app和data.bizTypes两者选择一个 |
| app | String | 否 | 对应一类boc，优先使用此字段ALL:所有应用CRM:CRM下所有子类型应用TASK:任务应用 |
| bizType | List | 否 | 具体的业务类型 |

## 请求示例

```json
{
  "includeNull": true,
  "data": {
    "app": "",
    "bizType": ""
  },
  "appId": ""
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| data | List | 数据集 |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "data": [

      "bizType": "452",
      "notReadCount": 0,
      "notDealCount": 0,
      "notDealTemporaryCount": 0,
      "extendCount": [

          "key": "452_notDeal",

        },
        {
          "key": "452_notDealTemporary",
          "notReadCount": 0,
          "notDealCount": 0
        }
      ]

  ],

  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；

## 特殊说明

### bizTypes参数说明

| APP | 业务名称 | 包含的待办类型（bizType） |
| --- | --- | --- |
| CRM | CRM待办（审批流业务量CRM待办对象等） | 452:待处理的审批流程 457:待处理的业务流程 401:待分配的销售线索 402:待跟进的销售线索 404:待确认的销售订单 406:待确认的销售阶段 408:待确认的退款 410:待确认的开票申请 411:待确认的退货单 456:待发货的销售订单 460:待处理的阶段任务 403:待审核的报备客户 |
| FEED | feed业务 | MyTodoTask:任务待办 20:需要回执 11:待点评的工作汇报 13:待处理的协同审批 12:待执行的指令 15:待点评的指令 |
| ORDER | 深研工单 | waitApproval:待审批的工单 waitAssign:待指派的工单 waitCheckins:待服务的工单 waitDeal:待处理的工单 |
| ALL | 所有的待办 | 上面所有bizTypes |
