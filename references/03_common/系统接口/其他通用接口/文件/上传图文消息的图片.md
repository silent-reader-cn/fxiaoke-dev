# 上传图文消息的图片

## 描述

上传图文消息的图片

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/media/upload/message?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

调用示例（使用curl命令，用FORM表单方式上传一个多媒体文件）： curl -F "media=@test.jpg" http://open.fxiaoke.com/media/upload/message?corpAccessToken=xxx&corpId=xxx

上传的文件限制: 图片文件，最大5M，支持jpg, png, gif, bmp, jpeg格式，用于发送消息接口

请注意，mediaId是可复用的，同一个mediaId可用于图文消息的多次发送。

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| corpAccessToken | String | 是 | 企业应用访问公司合法性凭证 |
| corpId | String | 是 | 开放平台公司帐号 |
| media |  | 是 | 二进制流，form-data中媒体文件标识，有filename、filelength、content-type等信息 |

## 请求示例

```json
{
  "media": "hello"
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
