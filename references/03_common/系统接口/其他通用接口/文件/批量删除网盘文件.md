# 批量删除网盘文件

## 描述

根据文件/文件夹 ID 列表批量删除网盘节点，返回实际删除数量及被删除节点的路径列表。删除文件夹时其下子节点会一并删除。

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/deleteNetDiskFiles?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据MAP |
| fileIds | List[String] | 是 | 待删除的文件/文件夹节点 ID 列表，不能为空（可通过[批量查询网盘文件/文件夹的ID](https://developer.fxiaoke.com/openapi_v2/common/system/other/file/queryFileIdsByPaths.html)接口获取） |

## 请求示例

```json
{
  "data": {
    "fileIds": [
      "xxxx1",
      "xxxx2"
    ]
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| data | object | 返回数据 |
| deletedCount | Long | 实际删除成功的节点数量（等于 nPaths 的长度） |
| nPaths | List[String] | 被删除节点的路径列表；无删除结果时返回空数组 [] |

## 返回示例

```json
{
  "traceId": "E-O.fktest4234.1000-20260730180000-xxxxxx",
  "data": {
    "deletedCount": 2,
    "nPaths": [
      "N_202607_19_cxxx593.xlsx",
      "N_202601_22_xxxx.xlsx"
    ]
  },
  "errorDescription": "success",
  "errorMessage": "success",
  "errorCode": 0
}
```

## 注意事项

- 删除为批量操作： deletedCount 可能小于传入的 fileIds 数量（部分 ID 不存在或无权限）。调用方应以 nPaths 为准核对实际删除结果。
- 删除文件夹时，其下子节点会一并删除。
- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
