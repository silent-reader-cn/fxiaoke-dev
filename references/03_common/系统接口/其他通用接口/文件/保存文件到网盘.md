# 保存文件到网盘

## 接口概述

保存文件到网盘

## 请求说明

**请求方式**：POST + application/json<br>**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/saveFileToDir?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)<br>**请求头填写**：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

### 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据MAP |
| departmentIds | List<Integer> | 否 | 用户所属部门编号（可以为空，普通用户需要保存到部门文件夹时使用） |
| path | string | 是 | 需要保存到网盘的文件path（目前只支持企业文件，即以N_或TN_开头的文件） |
| fileName | string | 是 | 文件名 （需要携带文件类型扩展名,文件名总长度不允许超过128,扩展名长度不允许超过20） |
| category | string | 是 | 网盘文件夹类型 （1 公司 2 个人 3 分享，目前暂不支持保存到分享文件夹） |
| folderPath | string | 是 | 文件夹路径 (绝对路径,必须以/ 开始 以文件名结束，最大支持嵌套层级 9) |
| autoCreateDir | boolean | 否 | 是否自动迭代创建缺失文件路径 (默认false) |
| allowReName | boolean | 否 | 是否允许以增量形式重命名文件名称 (例如：test.pdf-> test(1).pdf 依次递增，默认 false) |

### 请求示例

```json
{
  "data": {
      "departmentIds": [],
      "path": "N_202607_2xxxxxx.jpg",
      "fileName": "N_202607_23_xxxxx.jpg",
      "category": 1,
      "folderPath": "/test",
      "autoCreateDir": true,
      "allowReName": true
  }
}
```

## 返回说明

### 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 唯一请求ID |
| errorCode | integer | 状态码 |
| errorMessage | string | 错误信息 |
| data | object | 返回数据，具体字段见下表 |
| folderId | string | 文件夹ID |
| fileId | string | 文件Npath |
| fileName | string | 文件名 |
