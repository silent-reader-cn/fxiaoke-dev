# 文件下载

## 描述

1. 生成文件预下载URL
2. 通过上一步接口返回的url下载文件

## 第一步 生成文件预览URL

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/generatorDownloadUrl?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据MAP |
| expireTime | Int | 是 | 过期时间,最小60秒，最大604800秒 |
| globalAcceleration | Boolean | 否 | 是否开启全球加速，默认false |
| fileInfo | Map | 是 | 文件基本信息 |
| path | String | 是 | 文件ID，必须以N_、TN_、C_、TC_开头，长度不超过48 |
| filename | String | 是 | 文件名，最长120字符 |
| extension | String | 是 | 文件扩展名，不带点号 |

## 请求示例

```json
{
  "data": {
    "expireTime": 120,
    "globalAcceleration": false,
    "fileInfo": {
      "path": "",
      "extension": "",
      "filename": ""
    }
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| data | object | 返回数据 |
| path | string | 文件路径 |
| url | string | 下载URL |

## 返回示例

```json
{
    "traceId": "E-O.fktest4234.1000-20260625115831-13f7a4",
    "data": {
        "path": "N_202606_25_48e30432ea2c4e0b935f7482fa214c44.pdf",
        "url": "https://img.xxxx.com/FilesOne/xxxxxx"
    },
    "errorDescription": "success",
    "errorMessage": "success",
    "errorCode": 0
}
```

## 第二步：下载文件

- 使用第一步返回的结果中的url下载文件

```
curl -O https://img.xxxx.com/FilesOne/xxxxxx
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
