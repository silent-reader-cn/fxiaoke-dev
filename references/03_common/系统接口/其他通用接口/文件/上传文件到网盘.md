# 上传文件到网盘

## 描述

上传文件到网盘

## 请求说明

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/pages/open-api/guide/cloud/cloud/)/media/uploadToNetDisk<br>**请求方式**：POST<br>**Content-Type**：application/json *(注：由于参数中包含文件流 media，实际调用时通常需要以混合表单提交)*

**文件最大支持 50M**

## 请求参数说明

| 参数名 | 参数类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| corpAccessToken | String | **是** | 企业应用访问公司合法性凭证 |
| corpId | String | **是** | 开放平台公司帐号 |
| currentOpenUserId | String | **是** | 当前操作人的 openUserId |
| media | File | **是** | 上传的文件，form-data 中媒体文件标识，包含 filename、filelength、content-type 等信息 |
| folderPath | String | **是** | 上传至该目录，文件目录用 “/” 分割 |
| fileOverride | Boolean | **是** | 是否覆盖已存在文件 |
| category | Integer | **是** | 文件分类：<br>1. 公司文件<br>2. 个人文件 |

## 返回参数说明

| 参数名 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| errorCode | Integer | **是** | 返回码（0 代表成功） |
| errorMessage | String | **是** | 对返回码的文本描述内容 |
| data | Object | 否 | 接口返回的核心数据结构 |
| └ folderId | String | 否 | 目标文件夹 ID |
| └ fileId | String | 否 | 上传成功后的文件 ID |
| └ override | Boolean | 否 | 是否执行了覆盖操作 |
| traceId | String | 否 | 请求链路追踪 ID |

## 示例

## 请求示例

```json
{
  "corpAccessToken": "${corpAccessToken}",
  "corpId": "${corpId}",
  "currentOpenUserId": "${currentOpenUserId}",
  "media": "@/D:/test.pdf",
  "category": 2,
  "folderPath": "/",
  "fileOverride": true
}
```

## 响应示例

```json
{
    "errorCode": 0,
    "errorMessage": "success",
    "data": {
        "folderId": "xxxxxx0000000000000000",
        "fileId": "9d8113a0679xxxxcaae9d77caa",
        "override": true
    },
    "traceId": "E-O.74164.1063-47e1ad2395134ca9"
}
```
