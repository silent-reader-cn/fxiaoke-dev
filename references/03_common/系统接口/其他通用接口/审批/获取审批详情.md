# 获取审批详情

## 描述

获取审批详情

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/approval/get?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| startTime | Long | 是 | 开始时间时间戳 |
| endTime | Long | 是 | 结束时间时间戳 |
| pageSize | Int | 否 | 页容量(默认为20，最大不超过1000) |
| pageNumber | Int | 否 | 页号(默认为1) |
| approvalFormId | String | 否 | 审批类型ID |

## 请求示例

```json
{
  "includeNull": true,
  "pageNumber": 1,
  "approvalFormId": "0076E076-2D2B-4392-8365-7982763840C4",
  "pageSize": 10,
  "startTime": 1482809339093,
  "endTime": 1482809349093
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
