# 更新任意币种之间的汇率

## 描述

更新任意币种之间的汇率

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/custom/v2/data/updateCurrencyExchangeRate?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| toCurrencyCode | String | 是 | 目标币种 |
| currencyExchangeArgs | List | 是 | 转换参数 |
| fromCurrencyCode | String | 是 | 来源币种 |
| toCurrencyCode | String | 是 | 目标币种 |
| exchangeRate | String | 是 | 来源币种转目标币种的汇率 |

## 请求示例

```json
{
  "data": {
    "currencyExchangeArgs": [
      {
        "exchangeRate": "6.4354",
        "toCurrencyCode": "CNY",
        "fromCurrencyCode": "USD"
      }
    ],
    "toCurrencyCode": "CNY"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
