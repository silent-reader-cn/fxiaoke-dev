# 调用自定义函数(仅支持控制器函数)

## 描述

调用自定义函数(仅支持控制器函数)

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/special/function?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| api_name | String | 是 | 函数的apiName |
| postId | String | 是 | 业务生成的唯一ID（用于实现可幂性） |
| parameters | List | 是 | 执行函数传递的参数 |
| name | String | 否 | 参数名称 |
| type | String | 否 | 参数类型 |
| value | String | 否 | 参数值 |

## 请求示例

```json
{
  "data": {
    "api_name": "func_openapi_test__c",
    "postId": "dc18904b-6c99-xxxxxxx",
    "parameters": [
      {
        "name": "data",
        "type": "Map",
        "value": {
          "param1": "",
          "param2": "",
          "param3": ""
        }
      }
    ]
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
