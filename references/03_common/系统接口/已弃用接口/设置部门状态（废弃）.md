# 设置部门状态（废弃）

## 不建议继续使用下线接口，使用[修改部门对象信息](https://developer.fxiaoke.com/openapi_v2/object/OrganizationAndPersonnel/DepartmentObj/update.html)

## 描述

设置部门状态

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/data/update?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**此接口不维护，建议使用对象化接口（修改部门对象）**

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| corpAccessToken | String | 是 | 企业应用访问公司合法性凭证 |
| corpId | String | 是 | 开放平台公司帐号 |
| departmentId | Int | 是 | 部门ID |
| status | Int | 是 | 状态（1:禁用，2:启用） |

## 请求示例

```json
{
  "corpAccessToken": "{corpAccessToken}",
  "corpId": "{corpId}",
  "departmentId": 1,
  "status": 1
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
