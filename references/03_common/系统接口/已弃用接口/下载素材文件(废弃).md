# 下载素材文件(废弃)

## 描述

下载素材文件(废弃)，请使用[下载文件](https://developer.fxiaoke.com/openapi_v2/common/system/other/file/download.html)

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/media/download?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| mediaTypeDesc | String | 是 | 固定取值,图片:IMAGE,文件:DOCUMENT |
| igonreMediaIdConvert | Boolean | 是 | 是否忽略mediaId转换；当mediaId为npath(以N_开头)时传true，当mediaId不是napth时传false |
| mediaId | String | 是 | 素材ID或文件Npath |
| corpAccessToken | String | 是 | 企业应用访问公司合法性凭证 |
| corpId | String | 是 | 开放平台公司帐号 |

## 请求示例

```json
{
  "mediaTypeDesc": "DOCUMENT",
  "mediaId": "MEDIA_ID",
  "igonreMediaIdConvert": "true"
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
