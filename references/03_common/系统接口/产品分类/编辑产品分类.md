# 编辑产品分类

## 描述

编辑产品分类

## 请求说明

**请求方式** ：POST + application/json

**请求路径** ：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/data/editProductCategory?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 接口参数Map |
| editFlag | int | 是 | 操作类型;1:新增,2:更新,3:删除 |
| id | String | 编辑、删除时必填 | 产品分类的唯一id |
| name | String | 新增时必填 | 产品分类的单选label,对应于crm描述中单选的label |
| pid | String | 否 | 产品分类的父分类节点id |
| orderField | int | 新增时必填 | 产品单位在本级的排列序号 |
| category_code | String | 新增时必填 | 产品分类 |

## 请求示例

```json
{
  "data": {
    "editFlag": 1.0,
    "id": "123",
    "name": "蔬菜1",
    "pid": "2c188941cded4c74b348338a4415f265",
    "category_code": "123",
    "orderField": 3.0
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
