# 相关团队新增

## 描述

相关团队新增

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/team/add?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| apiName | String | 是 | 对象apiName(目前支持AccountObj和OpportunityObj) |
| data | Map | 是 | 数据map |
| dataIDs | List | 是 | 数据ID列表 |
| teamMemberEmployee | List | 是 | 成员ID列表 |
| teamMemberRole | String | 是 | 成员角色（1:负责人2:联合跟进人3:售后服务人员4:普通成员） |
| teamMemberPermissionType | String | 是 | 相关团队权限类型(1:只读2:读写) |
| ignoreSendingRemind | Boolean | 否 | 是否忽略发送CRM消息提醒，ture表示忽略，false不忽略；默认false不忽略 |

## 请求示例

```json
{
  "apiName": "AccountObj",
  "data": {
    "teamMemberEmployee": [
      "1000"
    ],
    "dataIDs": [
      "289eb6014a344c3b8e62cafc94bd2fef"
    ],
    "teamMemberRole": "1",
    "ignoreSendingRemind": "false",
    "teamMemberPermissionType": "1"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
