# 获取部门下成员简略信息

## 描述

获取部门下成员简略信息

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/user/simpleList?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| departmentId | Int | 是 | 部门ID, 为非负整数，999999 代表全公司，该id可以获取全公司人员 |
| fetchChild | Boolean | 否 | true:获取其所有子部门员工; false(默认):只获取当前部门员工 |

## 请求示例

```json
{
  "includeNull": true,
  "departmentId": 1000,
  "fetchChild": false
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| userList | List | 成员信息列表 |
| openUserId | string | openUserId |
| name | string | 名称 |
| nickName | string | 昵称 |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "userList": [
    {
      "openUserId": "1000",
      "name": "小明",
      "nickName": "小明"
    },
    {
      "openUserId": "1000",
      "name": "小红",
      "nickName": "小红"
    }
  ],
  "traceId": "E-O.827xxxxxx",
  "errorCode": 0,
  "errorMessage": "success",
  "errorDescription": "成功"
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
