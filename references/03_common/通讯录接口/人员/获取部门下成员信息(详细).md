# 获取部门下成员信息(详细)

## 描述

获取部门下成员信息(详细)

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/user/list?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| departmentId | Int | 是 | 部门ID |
| fetchChild | Boolean | 是 | 如果为true，则同时获取其所有子部门员工; 如果为false或者不传，则只获取当前部门员工 |
| showDepartmentIdsDetail | Boolean | 是 | 如果为true，则会返回员工主属部门(mainDepartmentId)与附属部门(attachingDepartmentIds) |

## 请求示例

```json
{
  "includeNull": true,
  "departmentId": 1,
  "showDepartmentIdsDetail": false,
  "fetchChild": false
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| userList | List | 成员信息列表 |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
