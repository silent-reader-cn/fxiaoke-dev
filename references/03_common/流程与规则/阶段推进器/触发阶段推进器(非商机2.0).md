# 触发阶段推进器(非商机2.0)

## 描述

触发阶段推进器(非商机2.0)

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/instance/triggerByRule?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| objectId | String | 是 | 数据id |
| entityId | String | 是 | 发起对象apiName |
| objectId | String | 是 | 发起对象的_id，可以通过条件查询接口获取 |

## 请求示例

```json
{
  "data": {
    "entityId": "AccountObj",
    "objectId": "6093aec2e4101b000138259c"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |
| data | Map | 接口返回数据 |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0,
  "data": {

  }
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
