# 完成对象数据发起的任务

## 描述

完成对象数据发起的任务

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/special/task/updateDataAndCompleteTask?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| data | Map | 是 | 数据map |
| taskId | String | 是 | 任务实例id |
| entityId | String | 是 | CRM对象apiName |
| objectId | String | 是 | CRM对象数据id |
| data | Map | 否 | 要修改的字段值 |

## 请求示例

```json
{
  "data": {
    "data": {
      "field_9B1wt__c": 1600045915000,
      "field_Dc51s__c": 1602637915000,
      "field_xV3Zw__c": "646546546"
    },
    "entityId": "AccountObj",
    "taskId": "5f68c4b68c0f3100014611e0",
    "objectId": "5eb2d3ea909a7a000118db8"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
