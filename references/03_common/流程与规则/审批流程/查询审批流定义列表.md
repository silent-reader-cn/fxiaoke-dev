# 查询审批流定义列表

## 描述

查询审批流定义列表

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/v2/special/approval/getDefinitionByPage?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| data | Map | 是 | 数据map |
| entityId | String | 是 | 流程所属对象 |
| workflowName | String | 是 | 流程名称 |
| enable | Boolean | 否 | true查询启用的,false停用的,为空则查询全部 |
| linkAppEnable | Boolean | 是 | true,则表示查询的是绑定互联应用的流程 |
| pageInfo | Map | 是 | 流程实例id |
| pageSize | Int | 是 | 最大条数是 20, 如果超过 20 会设置为 20 |
| pageNumber | Int | 是 | 页号 |

## 请求示例

```json
{
  "includeNull": true,
  "data": {
    "enable": true,
    "linkAppEnable": false,
    "pageInfo": {
      "pageNumber": 1,
      "pageSize": 20
    },
    "entityId": "xxx",
    "workflowName": "子流程"
  }
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | [查看错误码](https://developer.fxiaoke.com/openapi_v2/start/guide/codes.html) |

## 返回示例

```json
{
  "traceId": "E-O.827xxxxxx",
  "errorDescription": "success",
  "errorMessage": "OK",
  "errorCode": 0
}
```

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
