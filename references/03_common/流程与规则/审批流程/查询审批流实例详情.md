# 查询审批流实例详情

## 描述

查询审批流实例详情

## 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/crm/approvalInstance/get?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

**请求头填写** ：参考[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

## 请求参数

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| includeNull | Boolean | 否 | 是否包含 null 字段,false:不返回,true:返回，不传默认为false |
| instanceId | String | 是 | 流程实例Id（通过 查询对象审批路实例 接口获取，返回值instances.instanceId即为审批流的实例id） |

## 请求示例

```json
{
  "includeNull": true,
  "instanceId": "5f68c4b68c0f3100014611df"
}
```

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| traceId | string | 请求唯一ID |
| errorDescription | string | 错误描述 |
| errorMessage | string | 错误信息 |
| errorCode | Int | 错误码 |
| instanceDetail | Map | instanceDetail |
| instance | String | 流程实例详情 |
| tasks | Map |  |
| id | String | 任务id |
| tasks | String | 任务类型 单人审批(一个人过就过):single 多人审批(多个人当中一个人通过就过):one_pass 会签(所有人都通过才过):all_pass |
| state | String | 任务状态 进行中 in_progress ;通过 pass;自动通过 auto_pass;拒绝 reject;取消 cancel;回退 go_back;自动回退 auto_go_back;定时 schedule;异常 error |
| flowApiName | String | 审批流 apiName |
| createTime | String | 创建时间 |
| modifyTime | String | 最后更新时间 |
| opinions | String | 审批意见 |
| unCompletePersons | String | 未完成人员列表 |
| endTime | String | 完成时间 |
| completeOpenPersons | String | 已完成人员列表 |

## 注意事项

- 不能使用返回值的message字段做逻辑判断，errorMessage会有变化；
