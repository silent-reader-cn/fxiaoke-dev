# 旧版传参方式说明

## 调用接口获取AccessToken和corpId

### 请求说明

**请求方式**：POST + application/json

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/cgi/corpAccessToken/get/V2?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

### 请求参数

| 参数 | 参数类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| appId | String | 是 | AppId(企业应用ID) ，获取方式见[快速入门4.3部分](https://developer.fxiaoke.com/openapi_v2/start/quickstart/start.html) |
| appSecret | String | 是 | APPSecret(企业应用凭证密钥) ，获取方式见[快速入门4.3部分](https://developer.fxiaoke.com/openapi_v2/start/quickstart/start.html) |
| permanentCode | String | 是 | 永久授权码，获取方式见[快速入门4.3部分](https://developer.fxiaoke.com/openapi_v2/start/quickstart/start.html) |

### 请求示例

```json
{
  "appId":"APPID",
  "appSecret":"APPSECRET",
  "permanentCode":"PERMANETCODE"
}
```

### 返回参数

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| errorCode | 是 | 返回码 |
| errorMessage | 是 | 对返回码的文本描述内容 |
| corpAccessToken | 是 | 企业应用访问公司合法性凭证 |
| corpId | 是 | 开放平台派发的公司帐号 |
| expiresIn | 是 | 企业应用访问公司合法性凭证的过期时间，单位为秒，取值在0~7200之间，在过期时间在0-6600之间请求该接口会返回相同的corpAccessToken，在6600-7200之间请求该接口会返回新的token，如果要续期token，则需要在该时刻进行请求。 |

## 调用具体接口

不设置请求头，把公共参数写在请求体中。

### 请求示例

```json
{
  "corpAccessToken": "{corpAccessToken}",
  "currentOpenUserId": "{currentOpenUserId}",
  "corpId": "{corpId}",
  "data": {}
}
```
