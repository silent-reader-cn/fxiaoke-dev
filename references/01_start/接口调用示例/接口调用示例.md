# 接口调用示例

本教程以调用创建对象接口为示例，其他接口的调用方式也是类似的。

## 操作示例

![步骤1](https://a9.fspage.com/FSR/docs/openapi/open-api/guide/api/example-1.png)

1.
  参考[接口文档](https://developer.fxiaoke.com/openapi_v2/object/CommoditiesAndProducts/ProductObj/add.html)选择请求方式
2.
  参考[接口文档](https://developer.fxiaoke.com/openapi_v2/object/CommoditiesAndProducts/ProductObj/add.html)输入请求路径
3.
  **设置 Header 信息**，具体操作参考 [公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)
4.
  点击 “Body”，设置请求体信息
5.
  点击选择 “raw”
6.
  确认选择格式为 “JSON”
7.
  将[接口文档](https://developer.fxiaoke.com/openapi_v2/object/CommoditiesAndProducts/ProductObj/add.html)的请求示例复制到内容输入框，然后填入参数，可[参考说明](https://developer.fxiaoke.com/openapi_v2/start/guide/param.html)
8.
  点击发送请求
9.
  查看返回结果
