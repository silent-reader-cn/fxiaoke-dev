# 所在云域名

## 接口地址需填入企业所在云对应的域名

纷享云：open.fxiaoke.com

其他云地址：`open-${当前云登录域名}`

例如：

华为云：open-hwcloud.fxiaoke.com

阿里云：open-ale.fxiaoke.com

香港华为：open-ksc.sharecrm.com

法兰克福：open-hws.fxiaoke.com

北美云：open-na.sharecrm.com
