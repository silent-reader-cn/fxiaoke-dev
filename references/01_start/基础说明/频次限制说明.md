# 频次限制说明

单接口调用限制：100次/20秒；如需提升，请咨询纷享相关人员，购买独立库产品。

总接口调用次数限制(按天)：根据购买的 Open API[100000次] 的资源包 进行统计，如需提高，请购买多个则次数会进行叠加。

具体的付费策略，请咨询纷享客服。
