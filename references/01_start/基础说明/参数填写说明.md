# 参数填写说明

本文以调用创建对象接口为示例，其他接口的参数填写方式也是类似的。

## 获取对象字段列表

调用[查询对象描述](https://developer.fxiaoke.com/openapi_v2/common/system/object-describe/describe.html)接口，可以获取指定对象的描述信息、字段列表、字段信息

对于管理员，可以在管理后台获取字段列表

![图片](https://a9.fspage.com/FSR/docs/openapi/open-api/guide/param/param-1.png)

## 如何填写字段值

对于不同类型的字段，有不同的填写规范。

参考下方的层级结构，找到 "type" 字段的对应值，然后在[字段值说明](https://developer.fxiaoke.com/openapi_v2/start/guide/values.html)找到对应的字段类型，并按要求填写相应格式的值

```
顶层对象
└─ data
   └─ describe（业务对象描述）
      └─ fields（字段集合）
         └─ [具体字段名]（单个字段）
            └─ type（字段类型）
```
