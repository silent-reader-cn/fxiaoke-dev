# 全局返回码

每次调用接口时，可能获得正确或错误的返回码。企业应用可以参考本文的返回码信息进行错误排查。

| -1 | 系统繁忙 |

| 10006 | 缺少参数scope |

| 10009 | 缺少参数appAccount |
| 10010 | 缺少参数openUserId |
| 10012 | 缺少参数permanentCode |
| 10013 | 缺少参数corpAccessToken |
| 10014 | 缺少参数corpId |
| 10015 | 缺少参数toUser |
| 11001 | 参数appId不合法 |
| 11002 | 参数appSecret不合法 |
| 11003 | 参数appAccessToken不合法 |
| 11004 | 参数redirectUri不合法 |

| 32000 | 参数错误 |
| 40010 | templateId不合法 |
