# 应用免登

在纷享上开发的企业内部应用，可以通过该方式无需输入账号密码即可直接登录该内部应用。

## 流程图

![应用免登流程图](https://a9.fspage.com/FSR/docs/openapi/open-api/login/app-1.png)

## 获取 code

参考 [OAuth授权认证](https://developer.fxiaoke.com/openapi_v2/start/auth/auth-code.html) 中的 **获取code** 部分

## 通过 code 获取用户信息

### 请求说明

**请求方式**：post+application/json 方式

**请求路径**：https://[${填入所在云的域名}](https://developer.fxiaoke.com/openapi_v2/start/guide/cloud.html)/oauth2.0/getUserInfoByCode?thirdTraceId=[${随机字符串}](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)

### 请求参数

| 参数 | 参数类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| appId | String | 是 | 自建应用AppId |
| appSecret | String | 是 | 自建应用APPSecret |
| code | String | 是 | 上一步获取的code |
| authType | Integer | 否 | 认证类型，默认为0（OpenAPI），如填1（微信小程序），还会返回 sessionKey |

### 请求示例

```
{
	"appId": "FSAID_xxxxx",
	"appSecret": "xxxxxxxxxxxxxxxx",
	"code": "authorization_code"
}
```

### 返回参数

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| data | 是 | 用户的openUserId |

### 返回示例

```
{
	"errorCode": 0,
	"errorMessage": "success",
	"data": "openUserId"
}
```
