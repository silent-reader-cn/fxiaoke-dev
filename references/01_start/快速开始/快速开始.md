# 快速开始

本文旨在帮助开发者快速熟悉纷享开放平台的接口能力，快速掌握使用流程，实现业务数据的获取与插入操作。

## 步骤一：登录并创建企业自建应用

### 1. 登录纷享销客网页版，进入管理后台

![步骤1](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-1.png)

### 2. 找到 "应用列表"，点击右上方的 "新建企业自建应用"

![步骤2](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-2.png)

### 3. 填写应用信息并保存：

![步骤3](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-3.png)

其中APP端跳转地址和WEB端跳转地址 可以选填一个，如果没有则可以默认填写https://www.fxiaoke.com **APP端跳转地址**

在 “应用” 处，点击某个应用，跳转时会跳转到刚才填写的 “APP跳转地址”

![app](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-9.png)

**WEB端跳转地址**

在左侧栏找到 “更多”，找到需要的应用，点击后会跳转到刚才填写的 “WEB跳转地址”

![web](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-10.png)

### 4. 开启开发模式

需要使用 OpenApi 必须开启开发者模式。

#### 4.1 进入自建应用的配置页面,点击启用：

![步骤4](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-4.png)![步骤5](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-5.png)

#### 4.2 填写相关信息：

![步骤6](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-6.png)

1.
  登录授权发起页域名填入的是企业的第三方应用域名（注意，不包含http://或者https://前缀），用于纷享授权服务器验证 “请求来源是否合法”，是授权流程的 “入口身份标识”，使用场景如：[授权码模式](https://developer.fxiaoke.com/openapi_v2/start/auth/auth-code.html)。如果没有指定的登录页域名，可以填写www.fxiaoke.com 。
2.
  填写允许访问的白名单ip
3.
  服务号用于企信发消息，没有可不填

#### 4.3 点击确定后，可以看到调用开放平台需要的参数信息

| 参数 | 说明 |
| --- | --- |
| appId | AppId(企业应用ID) |
| appSecret | APPSecret(企业应用凭证密钥) |
| permanentCode | 永久授权码 |

![步骤7](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-7.png)

#### 4.4 CRM接口查询权限设置

**默认全部接口可用，为保障数据安全，建议自行设置精准访问区间**

![步骤8](https://a9.fspage.com/FSR/docs/openapi/open-api/quickstart/start-8.png)

## 步骤二：获取令牌

需要调用接口获取令牌作为身份凭证。具体操作流程参考：[OAuth授权认证](https://developer.fxiaoke.com/openapi_v2/start/auth/auth-code.html)

## 步骤三：调用 API

现在，你可以根据你的需求来调用纷享开放平台提供的 OpenAPI 了。开发对接程序时，请务必按[接口文档](https://developer.fxiaoke.com/openapi_v2/object/CommoditiesAndProducts/ProductObj/add.html)传参调用。如需体验调试 API，可以参考 [接口调用示例](https://developer.fxiaoke.com/openapi_v2/start/example/example.html)

## 特别说明

**请仔细阅读[公共参数填写](https://developer.fxiaoke.com/openapi_v2/start/example/public.html)，确保参数填写正确，注意新旧版本的参数填写方式不同**

如不熟悉字段获取以及参数填写等操作，建议先阅读[参数填写说明](https://developer.fxiaoke.com/openapi_v2/start/guide/param.html)

如有其他问题，请先参考[常见问题](https://developer.fxiaoke.com/openapi_v2/FAQ/deep-paging.html)。
