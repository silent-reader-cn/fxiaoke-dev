# 查看如何获取列表中的查询条件

使用OpenAPI对象列表查询时，文档中查询条件描述不全时，通过下面的方法能快速找到search_query_info参数

![查询条件获取方法1](https://a9.fspage.com/FSR/docs/openapi/open-api/other/FAQ/query-1.png)

1.
  按 f12 或右键点击 "检查"，打开下方的控制台
2.
  选择筛选条件
3.
  点击搜索按钮
4.
  找到 List 地址的请求，点击查看详情

![查询条件获取方法2](https://a9.fspage.com/FSR/docs/openapi/open-api/other/FAQ/query-2.png)

1.
  找到 "载荷"（Payload）
2.
  把 search_query_info 的内容复制出来
