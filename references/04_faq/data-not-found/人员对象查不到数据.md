# 人员对象查不到数据

有时候在使用**人员对象**会有**查不到数据**，或者**查到的数据不全**的问题，是因为人员对象有查询的权限控制，需要：

## 1. 方案一

申请人员对象接口查询权限产品灰度，由纷享客服在CRM产品灰度中申请

## 2. 方案二

![数据权限说明](https://a9.fspage.com/FSR/docs/openapi/open-api/other/FAQ/found-1.png)

1.
  点击 ① 所示部分设置列表查询接口权限
2.
  点击 ② 所示部分设置查询详细信息接口权限
3.
  点击 ③ 所示部分设置新增数据接口权限

数据共享文档说明: [https://www.fxiaoke.com/mob/guide/crmdoc/src/7-1-3%E6%95%B0%E6%8D%AE%E6%9D%83%E9%99%90%E7%AE%A1%E7%90%86.html](https://www.fxiaoke.com/mob/guide/crmdoc/src/7-1-3%E6%95%B0%E6%8D%AE%E6%9D%83%E9%99%90%E7%AE%A1%E7%90%86.html)

配置人员对象共享规则：

![人员对象配置共享规则1](https://a9.fspage.com/FSR/docs/openapi/open-api/other/FAQ/found-2.png)

1.
  找到 "数据管理权限"
2.
  点击 “数据共享”
3.
  下滑找到 “人员”
4.
  点击 "新建共享规则"

![人员对象配置共享规则2](https://a9.fspage.com/FSR/docs/openapi/open-api/other/FAQ/found-3.png)

1.
  规定哪些人员的数据被共享
2.
  选择共享的人员数据范围
3.
  设置谁能看到这些数据，如果指定某个人，则openapi查询时，x-fs-userid【[新的传参方式](https://developer.fxiaoke.com/openapi_v2/pages/open-api/guide/api/public/)】 或者 currentOpenUserId【[旧的传参方式](https://developer.fxiaoke.com/openapi_v2/pages/open-api/guide/api/old/)】 必须是这个人，否则无法查到共享的数据

配置完成后生效时间比较长，请耐心等待。当使用【openUserId】对应的用户登录，进行人员对象的列表页面，如果可以看到数据，则表明共享规则以及生效，此时可以使用接口查到数据。
